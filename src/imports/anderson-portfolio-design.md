Design a **modern full-stack developer portfolio website with a CMS-style admin dashboard**.

The base name of the website should be **“Anderson”**.

The platform consists of two parts:

1. **Public Portfolio Website**
2. **Admin Dashboard to manage the content of the website**

When the admin updates information (name, bio, projects, experience, skills, etc.), **the website should update automatically in real time**.

The design should be **modern, minimal, and similar to high-end SaaS products like Vercel, Stripe, Linear, and Supabase dashboards.**
